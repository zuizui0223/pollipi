# Refine before deciding: an information-order theory for reference-guided observation and uncertainty-preserving inference

**Status:** conceptual/mathematical draft. Literature citations and journal-specific formatting are intentionally deferred until the structural argument is frozen.

## Abstract

Observation pipelines often compress uncertainty twice: first by replacing a rich measurement with a single corrected representation, and again by replacing process-preserving evidence with a single semantic label. We develop an information-order framework for separating these operations. Let a primary observation be generated by a latent target/process state together with an observation-side measurement state, and let an additional target-excluding reference provide information about the latter. We show that retaining the reference can only refine compatible-world and identified sets, whereas deterministic semantic coarsening can only expand them. In the additive special case, primary-only target/nuisance decomposition is non-identifiable without additional restrictions. For orthogonal reference-derived projection, target-to-nuisance energy ratio improves exactly when the fraction of nuisance captured by the reference subspace exceeds the fraction of target captured; consequently no nonzero reference-only projector can universally preserve an unrestricted target class. We then show that the decomposition pair consisting of reference-explained and residual components is exactly reversible, so information loss arises from discarding a branch rather than from decomposition itself. This motivates a set-valued formulation: a reference-derived compatible set of measurement-side states induces a compatible set of target states. Coverage of the measurement-state set transfers to target-state coverage, and in the additive normed case the two compatible sets have identical diameter. These results extend to arbitrary nonlinear forward models through existential inversion. At the decision level, richer retained observations cannot worsen the minimum achievable risk for a fixed decision problem, while deterministic coarsening cannot improve it. Ideal point-identification coverage obeys the same monotonicity. We connect this upstream refinement principle to a downstream uncertainty-preserving decision architecture: independent information may contract compatible states, but neither a derived representation nor a semantic conclusion is licensed merely by missing alternative evidence. The resulting rule is: **decompose without discarding, contract with independent information, and interpret without forcing.**

## 1. Introduction

Automated observation is usually framed as a prediction problem. A sensor records a signal, an algorithm removes nuisance variation, and a classifier assigns a label. This framing hides two logically different operations. The first changes what information is represented. The second decides what the represented information means.

These operations need not fail in the same way. A representation can become easier to classify while discarding a scientifically relevant distinction. Conversely, a rich representation can retain the necessary distinction while a downstream classifier forces incompatible processes into one exclusive label. A method that improves conventional detection metrics can therefore still manufacture certainty.

The problem is especially clear when an observation contains a local process of interest together with exogenous measurement variation. In visual systems, such variation can arise from motion, illumination, occlusion, blur, vibration, geometry or other measurement-side states. The physical cause need not itself be directly visible. A separate target-excluding region or sensor may nevertheless retain information about the shared measurement state. The natural question is then not simply whether that reference can be used to produce a better corrected image. It is whether the reference adds information that contracts the set of latent explanations compatible with the primary observation, and how that contraction should be propagated without discarding unresolved alternatives.

This paper develops that question as an information-order problem. We distinguish three operations:

1. **reference augmentation:** retaining an additional observation channel;
2. **representation decomposition:** exposing components or sets of explanations supported by the richer observation;
3. **semantic contraction:** deciding whether the remaining evidence supports a unique scientific statement.

The central thesis is that these operations have different mathematical guarantees. Adding a retained reference weakly refines information. Deterministic semantic coarsening weakly destroys information. A point correction, however, is not guaranteed to preserve the target because a reference-derived nuisance representation can overlap the target representation. The appropriate generic response is therefore not unconditional subtraction. It is non-destructive or set-valued decomposition followed by an explicit entitlement layer for semantic decisions.

The framework is deliberately target-independent. It does not require naming a nuisance such as wind, nor does it require a particular optical-flow model, neural network or image domain. A temporal-subspace nuisance model is one computational example, not the definition of the theory.

We derive twelve structural results. They establish an exact duality between upstream reference refinement and downstream semantic preservation, identify the conditions under which linear nuisance projection helps or harms, show how a reference-compatible nuisance set propagates to a target-compatible set, extend the contraction result to arbitrary nonlinear forward models, and connect information refinement to optimal decision risk and safely resolvable coverage. We then separate these theorem-level results from the empirical questions that remain: whether a physical reference is informative, whether a finite-sample compatible set is calibrated, and whether an implemented observer approximates the compatible-state geometry well enough in a target domain.

## 2. Compatible worlds and information order

### 2.1 Latent worlds and identified sets

Let `Omega` be a set of latent worlds. A world `omega` contains the target/process state of interest, the measurement-side state and any additional variables needed to specify the observation problem.

For any retained observation map `X`, define the compatible-world fiber

\[
\mathcal C_X(x)=\{\omega\in\Omega:X(\omega)=x\}.
\]

For an estimand `theta : Omega -> Theta`, define the identified set

\[
\mathcal I_X(x)=\{\theta(\omega):\omega\in\mathcal C_X(x)\}.
\]

The estimand is point identified at `x` when `I_X(x)` is a singleton. Otherwise it is partially identified.

This notation separates the information retained by the observation from any particular estimator or classifier used to approximate it.

### 2.2 Proposition 1 — retained reference information weakly refines identification

Let `Y` be the primary observation and `R` an additional retained reference. For every realized pair `(y,r)`,

\[
\mathcal C_{(Y,R)}(y,r)\subseteq\mathcal C_Y(y).
\]

Therefore for every estimand,

\[
\boxed{\mathcal I_{(Y,R)}(y,r)\subseteq\mathcal I_Y(y).}
\]

**Proof.** Every world satisfying `(Y,R)=(y,r)` also satisfies `Y=y`. Applying the estimand to a subset cannot generate values outside the image of the larger set. ∎

The statement requires that the reference be retained in addition to the primary record rather than silently replacing it. It does not require statistical independence of `R` and the latent processes. A useful reference is expected to depend on relevant measurement-side state. What must remain separate is the scientific definition of the reference from the target answer being inferred.

### 2.3 Proposition 2 — deterministic semantic coarsening weakly destroys identification

Let `E` be a rich evidence record and let `C=c(E)` be a deterministic coarsening. Then for every realized `e`,

\[
\mathcal C_E(e)\subseteq\mathcal C_C(c(e)),
\]

and hence

\[
\boxed{\mathcal I_E(e)\subseteq\mathcal I_C(c(e)).}
\]

**Proof.** If `E(omega)=e`, then `c(E(omega))=c(e)`. Thus every world compatible with the fine record is compatible with its coarsening. ∎

Reference augmentation and semantic coarsening therefore move in opposite directions in the information partial order:

\[
\sigma(Y)\subseteq\sigma(Y,R),
\qquad
\sigma(c(E))\subseteq\sigma(E).
\]

This is the first exact sister-method symmetry: add distinctions upstream; do not discard distinctions downstream before they are known to be irrelevant.

## 3. Why primary-only nuisance separation is not identified

### 3.1 Proposition 3 — additive non-identifiability

Consider

\[
Y=S+N,
\]

where `S` is a target/process contribution and `N` is a nuisance contribution in a common vector space. Without additional restrictions, `S` and `N` are not separately identifiable from `Y`.

For any perturbation `Delta`, define

\[
S'=S+\Delta,\qquad N'=N-\Delta.
\]

Then

\[
S'+N'=Y.
\]

Infinitely many distinct decompositions therefore produce the same primary observation. ∎

The proposition is intentionally simple. It establishes why an additional restriction is necessary if the scientific estimand concerns target and nuisance contributions separately. Such a restriction could be a reference channel, a structural model, an intervention, a negative control or a domain-specific constraint. No classifier can recover an unidentified decomposition from `Y` alone without importing such information implicitly.

## 4. Linear projection: exact benefit and exact failure boundary

Suppose a target-excluding reference is used to construct an orthogonal projector `P` onto a candidate nuisance subspace. Let

\[
Y=S+N.
\]

Define the fractions of target and nuisance energy captured by that subspace:

\[
a_S=\frac{\|PS\|^2}{\|S\|^2},
\qquad
 a_N=\frac{\|PN\|^2}{\|N\|^2}.
\]

### 4.1 Proposition 4 — exact energy-ratio tradeoff

Orthogonality gives

\[
\|(I-P)S\|^2=(1-a_S)\|S\|^2,
\]

\[
\|(I-P)N\|^2=(1-a_N)\|N\|^2.
\]

For the target-to-nuisance energy ratio,

\[
\frac{\mathrm{SNR}_{after}}{\mathrm{SNR}_{before}}
=
\frac{1-a_S}{1-a_N}.
\]

Hence

\[
\boxed{\mathrm{SNR}_{after}>\mathrm{SNR}_{before}\iff a_N>a_S.}
\]

This gives a precise answer to a question that is often left qualitative. A reference is not useful merely because it explains substantial variation. The relevant contrast is how much of the nuisance it captures relative to how much target structure it captures.

### 4.2 Proposition 5 — universal non-harm is impossible for a nonzero reference-only projector

Assume the admissible target class contains arbitrary nonzero vectors in the observation space. If `P` is nonzero, its range contains a nonzero vector `S`. For that target,

\[
PS=S,
\qquad
(I-P)S=0.
\]

Thus a nonzero projector can completely erase an admissible target. ∎

A target-excluding reference therefore does not by itself imply a target-orthogonal nuisance subspace. Target exclusion is a property of the reference scene or sensor; orthogonality is a property of temporal or feature geometry.

This impossibility result changes the generic design goal. A method need not seek a universally safe corrected signal because such a guarantee is unavailable over an unrestricted target class.

## 5. Decomposition without discarding

### 5.1 Proposition 6 — the decomposition pair is exactly reversible

Define

\[
E=PY,
\qquad
Z=(I-P)Y.
\]

Then

\[
\boxed{Y=E+Z.}
\]

The map `Y -> (E,Z)` is injective. Its inverse is simply addition. This holds for any linear `P`; orthogonality is not required for the algebraic identity.

Therefore computing explained and residual components is not itself an information-losing operation when both components are retained losslessly. The destructive step is discarding a component—for example, replacing the full measurement record by `Z` alone.

If `P` has nonzero range and `v` lies in that range, then

\[
(I-P)(Y+v)=(I-P)Y
\]

for an orthogonal projector. Distinct observations can collapse to the same residual.

This motivates a revised interpretation: nuisance decomposition should be treated as an additional evidence representation, not as an irreversible correction by default.

## 6. Reference-guided partial decomposition

A point projection still commits to one nuisance representation. The closer mathematical sister to partial identification is set-valued.

### 6.1 Additive compatible sets

Suppose the reference yields a nuisance-compatible set

\[
\mathcal N(R).
\]

Define

\[
\boxed{
\mathcal S(Y,R)=\{Y-n:n\in\mathcal N(R)\}.
}
\]

### 6.2 Proposition 7 — compatible-set coverage transfer in the additive case

If the true nuisance `N` lies in `N(R)`, then because `S=Y-N`, the true target lies in `S(Y,R)`.

Consequently, if a random compatible set satisfies

\[
P\{N\in\mathcal N_\alpha(R)\}\ge 1-\alpha_R,
\]

then

\[
\boxed{
P\{S\in\mathcal S_\alpha(Y,R)\}\ge 1-\alpha_R.
}
\]

### 6.3 Proposition 8 — exact uncertainty-width transfer

For any norm-induced metric, `n -> Y-n` is an isometry. Therefore

\[
\boxed{
\operatorname{diam}\mathcal S(Y,R)=
\operatorname{diam}\mathcal N(R).
}
\]

If reference information contracts the nuisance-compatible set, the target-compatible set contracts by the same translated geometry.

If `N(R)={N}`, the target is point identified. If the reference leaves the nuisance set unchanged, no target identification is gained.

These results suggest measuring reference value by valid compatible-set contraction rather than point-estimator accuracy alone.

## 7. Beyond additive images: arbitrary observation forward models

The additive model is analytically transparent but not generic. Occlusion, blur, saturation, exposure and geometry can be nonlinear.

Let

\[
\boxed{Y=F(S,M)},
\]

where `M` is a measurement-side latent state containing nuisance, geometry, visibility and sensor state.

Let a reference induce a compatible measurement-state set `M(R)`. Define

\[
\boxed{
\mathcal S_F(y,R)=
\{s:\exists m\in\mathcal M(R)\text{ with }F(s,m)=y\}.
}
\]

### 7.1 Proposition 9 — general forward-model contraction

If

\[
\mathcal M(R_2)\subseteq\mathcal M(R_1),
\]

then

\[
\boxed{
\mathcal S_F(y,R_2)\subseteq\mathcal S_F(y,R_1).
}
\]

**Proof.** Any target state compatible under `R2` has a witness `m` in `M(R2)`. The same witness belongs to the larger `M(R1)`. ∎

No linearity or projection assumption is required.

### 7.2 Proposition 10 — general coverage transfer

If the true world satisfies `Y=F(S,M)` and the reference-derived measurement-state set contains the true `M`, then the target-compatible set contains the true `S`, because the true pair itself is a witness.

Thus

\[
P\{M\in\mathcal M_\alpha(R)\}\ge 1-\alpha_R
\]

implies

\[
\boxed{
P\{S\in\mathcal S_{F,\alpha}(Y,R)\}\ge 1-\alpha_R.
}
\]

This result identifies the empirical burden precisely. A narrow set is not enough; the reference-derived set must be valid. Arbitrarily excluding the true measurement state can create false precision.

The reference need not be statistically independent of the target or nuisance. “Independent” here means that the reference is an additional channel defined without using the target answer being inferred. Reference acquisition is also assumed non-destructive; if measuring the reference changes the primary system, the intervention belongs in the forward model.

## 8. Optimal decision risk under information refinement and coarsening

Let a fixed decision problem have action `a`, latent world `omega` and loss `L(a,omega)`. Let `R*(X)` be the minimum expected risk among all decision rules measurable with respect to observation `X`.

### 8.1 Proposition 11 — richer retained information cannot worsen optimal risk

Because every rule based on `Y` can be implemented from `(Y,R)` by ignoring `R`,

\[
\boxed{R^*(Y,R)\le R^*(Y).}
\]

Conversely, if `C=c(E)` is a deterministic semantic coarsening, every `C`-based rule can be implemented from rich `E` by first applying `c`. Therefore

\[
\boxed{R^*(E)\le R^*(C).}
\]

These inequalities concern the best achievable rule class. A particular restricted algorithm can perform worse after receiving more information if it is forced to use that information badly.

## 9. Ideal safely resolvable coverage

For estimand `theta`, define

\[
J_X(\omega)=
\mathbf 1\{|\mathcal I_X(X(\omega))|=1\}.
\]

Let

\[
C_X=P\{J_X=1\}
\]

be ideal point-identification coverage.

### 9.1 Proposition 12 — resolvable coverage is monotone in the information order

If `X2` refines `X1`, then

\[
\boxed{J_{X2}(\omega)\ge J_{X1}(\omega)}
\]

for every world, and therefore

\[
\boxed{C_{X2}\ge C_{X1}.}
\]

A case already point identified under a coarse observation remains point identified in every refined subset of its compatible-world fiber. Some previously ambiguous cases may become identifiable.

For deterministic semantic coarsening, the inequality reverses: rich evidence has point-identification coverage at least as large as its coarsening.

This theorem clarifies why an implemented reference-based observer can empirically lose target support without contradicting the value-of-information result. The information may be richer while the implemented observer fails to represent the true compatible-set geometry.

## 10. Downstream semantic entitlement

The upstream theory does not itself define a target, nuisance or absence state. Derived channels are measurement representations.

A downstream process-preserving decision layer should therefore maintain separate positive evidence for target, nuisance, observability and any independently validated absence channel. Target and nuisance may coexist. A quiet residual does not establish target absence. Reference-explained variation does not establish a named nuisance without calibration. If compatible target/process interpretations remain multiple, the appropriate output is unresolved rather than a forced unique label.

This creates the sister-method chain

\[
\boxed{
\text{world}
\rightarrow
\text{retained primary + reference information}
\rightarrow
\text{reversible/set-valued decomposition}
\rightarrow
\text{process-preserving evidence}
\rightarrow
\text{entitled decision or unresolved}
}
\]

rather than

\[
\text{world}\rightarrow\text{corrected image}\rightarrow\text{binary label}.
\]

## 11. Structural guarantees versus empirical questions

The mathematical results establish what follows from the stated information and forward-model assumptions. They do not establish that a particular physical reference is useful.

Empirical validation is still needed to determine:

- whether a physical target-excluding reference strictly contracts the relevant measurement-state set;
- whether a reference-derived compatible set achieves its declared coverage;
- whether nuisance capture exceeds target capture for a particular projection method;
- finite-sample stability of a learned/reference-derived representation;
- how well practical observers approximate compatible-set geometry;
- transport across sensor systems and applications;
- named causal attribution to a physical nuisance without additional structural or interventional evidence.

These are performance, calibration and transport questions. They are not logical prerequisites for Propositions 1–12.

## 12. Discussion

### 12.1 From correction to information refinement

The main conceptual change is to stop treating nuisance handling as a demand for one corrected signal. A target-excluding reference can be useful without identifying one true nuisance realization. Its value is to exclude measurement-side states that are no longer compatible with the observed reference while retaining the states that remain plausible.

This perspective separates two failures that point correction conflates. A reference can be genuinely informative while a chosen projection deletes target structure. Conversely, a representation can retain all information while a downstream observer maps it to overly certain labels. The correct diagnosis depends on the layer at which distinctions are lost.

### 12.2 Why reversible decomposition matters

If explained and residual components are both retained, linear decomposition is not itself an information bottleneck. This suggests a practical default: derived nuisance and residual channels should coexist with enough provenance to reconstruct the original measurement. Entitlement is then required before suppressing, discarding or semantically interpreting a component, not before computing a reversible summary.

### 12.3 Partial decomposition as the closest sister to uncertainty-preserving semantics

The set-valued formulation makes the symmetry strongest. Upstream, reference uncertainty induces a compatible set of measurement-side and target-side states. Downstream, semantic uncertainty induces a compatible set of process interpretations. At both layers, independent information may contract the set. Neither layer is required to manufacture a point answer before the set has contracted enough.

### 12.4 What real data add

Real data are important for a different reason than logical validity. They determine whether a physical reference supplies useful and calibrated contraction in a domain. They estimate the gap between the ideal compatible-set observer and the finite algorithm used in practice. They test transport. These are essential for deployment or domain-specific performance claims, but they do not determine the truth of the information-order results themselves.

## 13. Conclusion

Observation-process ambiguity should not be handled by forcing a choice between raw data and one corrected representation. Independent reference information weakly refines what is knowable, while deterministic semantic coarsening weakly removes what is knowable. The safe mathematical architecture therefore preserves richer observations, exposes reversible or set-valued decompositions, and delays semantic commitment until compatible states support a unique conclusion.

The compact principle is:

> **Refine before deciding. Decompose without discarding. Contract with justified information. Interpret without forcing.**
