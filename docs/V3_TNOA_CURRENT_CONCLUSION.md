# V3–TNOA current conclusion after two fresh bridge generations

Status: **canonical current synthesis. The end-to-end architecture is not promoted; the diagnostic value of the two-layer design is supported.**

## 1. What is now supported

The V3 and TNOA layers are empirically distinguishable rather than merely conceptually symmetric.

### Representation layer

The frozen V3 temporal-reference method repeatedly shows that correctly coupled target-free reference information contains useful nuisance information:

- original V3 matched reference improved frame-level target/nuisance separation over raw and time-broken controls;
- fresh bridge generation 1 increased safe unique-process coverage from `0.6000` raw to `0.8167` matched, with matched-minus-raw paired 95% CI `+0.2042 to +0.2333`;
- matched exceeded time-broken by `+0.1500`, CI `+0.1207 to +0.1792`;
- fresh trajectory bridge again increased safe unique coverage from `0.7750` raw to `0.8542` matched, paired CI `+0.0500 to +0.1083`;
- matched again exceeded time-broken (`+0.0708`, CI `+0.0292 to +0.1125`).

Thus correctly coupled reference information adds real usable structure in these controlled worlds.

### Decision-entitlement layer

TNOA revealed that representation improvement is **not sufficient** for safe inference.

Bridge generation 1 retained pooled false certainty `0.3194`, failing the frozen absolute ceiling `0.10`, because true target+nuisance superposition was often collapsed to unique nuisance.

Replacing frame-fraction target evidence with pre-existing multi-frame trajectory geometry improved:

- false certainty: `0.3125 -> 0.2407` raw → matched;
- paired difference: `-0.0718`, 95% CI `-0.1042 to -0.0394`;
- overlap abstention: `0.2969 -> 0.4635`;
- forced unique overlap: `0.7031 -> 0.5365`.

Yet the absolute false-certainty gate still failed, and matched target-only T retention fell from `0.8750` raw to `0.2708`.

Therefore the joint architecture remains **not promoted**.

## 2. Strongest methodological conclusion

The most useful conclusion is now:

> **Representation quality and inferential entitlement are separate problems. A target-free reference can add real information about shared disturbance, but neither reference availability nor improved classification metrics entitle the system to subtract that representation unconditionally or to make a unique target/nuisance statement.**

This conclusion is stronger than either component alone.

- Without V3, TNOA only says to preserve uncertainty when evidence conflicts or is missing.
- Without TNOA, V3 could appear solved because ordinary recall/FPR and balanced utility improved strongly.
- Together, the system can distinguish **information gain** from **permission to conclude**.

## 3. Refined symmetry

The symmetry is not simply “V3 removes noise, TNOA classifies.”

It is:

### V3 — representation entitlement

Question:

> What part of the recorded temporal structure is actually supported as shared with a target-free reference, and is applying that representation warranted?

Current failure boundary:

> target-free reference available ≠ nuisance correction entitled.

A short noisy reference can span target temporal components by chance; unconditional projection can therefore erase useful target geometry.

### TNOA — decision entitlement

Question:

> Given calibrated positive target, nuisance, observability and attribution evidence, is a unique B/T/N statement justified?

Established boundary:

> missing positive evidence ≠ negative truth, and simultaneous target+nuisance support should remain unresolved rather than be forced exclusive.

The shared principle is therefore:

> **positive support must license both representation changes and semantic decisions; otherwise preserve the unresolved state.**

## 4. Two distinct unresolved seams

The fresh bridges localize two remaining method seams.

### Seam A — target representation under superposition

A simple candidate-frame fraction was too weak under fixed-risk calibration. Existing path-efficiency/reversal geometry improved overlap preservation substantially but did not reduce false certainty below `0.10`.

This means target+nuisance superposition still contains unresolved information for the present observation family. That is not a reason to force classification.

### Seam B — nuisance-correction entitlement

In target-only worlds, unconditional matched-V3 projection degraded trajectory geometry:

- path efficiency about `0.895 -> 0.783`;
- reversal about `0 -> 0.073`;
- trajectory target-score mean about `0.349 -> 0.275`;
- final target-only T rate `0.875 -> 0.271`.

The next representation question is therefore not “how much more aggressively can V3 subtract?” but:

> **When is the reference sufficiently coupled to justify applying the nuisance projection at all?**

This is a representation-entitlement problem analogous to TNOA's decision-entitlement problem.

## 5. Why no third synthetic rescue is run now

Two post-V3 fresh generations have already:

1. confirmed repeatable coupling-specific information gain;
2. falsified end-to-end promotion under the frozen absolute-risk contract;
3. shown that multi-frame target geometry improves, but does not solve, overlap preservation;
4. exposed unconditional projection as a separate target-retention hazard.

Immediately adding another score, gate or threshold on the same synthetic family would increase post-hoc design risk.

The appropriate next evidence should therefore change the evidence source, not repeatedly tune the same synthetic world.

## 6. Next empirical step

Use a controlled real visual experiment chosen for identifiability rather than for pollination specificity.

Prospectively create blocks with:

- independent known local target/process truth;
- nuisance-on and nuisance-off conditions;
- a target-free nuisance reference;
- matched and time-broken reference controls;
- fixed acquisition interval and untouched heldout blocks.

The experiment should directly test both layers:

1. does matched reference improve representation when shared nuisance is truly present?
2. does it avoid damaging target evidence when nuisance is absent or weak?
3. at the same prefrozen TNOA false-certainty semantics, does safely resolvable coverage increase without forcing genuine superposition?

A controlled motion/illumination setup may be scientifically cleaner as the first external validation than a complex ecological scene. A later natural ecological system can then test transport.

## 8. One-sentence current result

> **Correctly coupled target-free reference information repeatedly improves the usable representation of local signal versus shared disturbance, but safe inference requires a second entitlement layer: the fresh V3–TNOA bridges show that information gain can coexist with excessive false certainty and with target loss when nuisance correction is applied without sufficient justification.**
